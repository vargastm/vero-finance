# vero-finance

## Technologies Used

### Framework and Core Library
- **Next.js 16** - React framework for production
- **React 19** - JavaScript library for building user interfaces
- **TypeScript** - JavaScript superset with static typing

### Styling
- **Tailwind CSS 4** - Utility-first CSS framework
- **Lucide React** - Icon library

### Web3 and Blockchain
- **RainbowKit** - Component kit for connecting Web3 wallets
- **Wagmi** - React hooks for Ethereum
- **Viem** - TypeScript library for interacting with Ethereum

### State Management and Data
- **TanStack React Query** - Library for server state management and caching

### External Services
- **Resend** - API for transactional email delivery

### Development Tools
- **ESLint** - Linter for JavaScript/TypeScript
- **Prettier** - Code formatter
- **TypeScript ESLint** - TypeScript-specific linter
